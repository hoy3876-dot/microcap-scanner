2. 상장목록에서 종목 찾기
상장목록을 먼저 불러오세요.
종목 유형 정책
ADR과 보통주를 모두 포함합니다. ETF·워런트·유닛·우선주 등은 공식 목록 수집 단계에서 제외합니다. ADR은 목록의 증권 유형과 회사명으로 판별하고 불확실하면 미분류로 둡니다.
3. 감시 후보 순위
후보 정보 입력
빈 항목은 미확인으로 저장됩니다. 미확인 항목은 점수 산정에서 제외하며 실제 데이터처럼 0으로 취급하지 않습니다.
상장목록은 현재 거래 가능 여부·가격·Float·투자 적합성을 보증하지 않습니다. 점수는 상승 확률이나 매수 신호가 아닙니다. 점수는 확인된 입력 항목만 반영하며 출처·기준일 검증이 필요합니다. 이 파일은 주가·Float·RVOL·Short Float·CTB 실시간 API는 아직 연결되어 있지 않습니다. SEC 공시는 GitHub Actions가 수집한 공개 제출 내역입니다.
